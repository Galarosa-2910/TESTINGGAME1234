# BIOHAZARD LAST STAND 
School project in collaborations with:
JOHN CODDY RIOSA
JOHN MARCO GALAROSA
RALLI CRIS QUEDA

## Description
A 2D survival game inspired by classic Resident Evil and bullet-heaven with roguelike action gameplay like Vampire Survivors.
Set in a quarantined city overrun by infected creatures, players must fight to survive against endless waves of zombies using automatically firing weapons. Defeat enemies, collect experience points, unlock powerful upgrades, and improve your arsenal as the outbreak becomes increasingly dangerous. With a retro survival-horror atmosphere, escalating enemy encounters, and score-based gameplay, your objective is simple: survive as long as possible and achieve the highest score.
